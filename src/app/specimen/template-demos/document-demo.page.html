Context windows

A model reads a fixed number of tokens per request. Everything it knows about your task has to fit inside that budget: the system prompt, the conversation so far, tool output and the files you pasted. The limit is set per model, for example 200k tokens.

A bigger window does not mean better recall. Details in the middle of a long context are easier to miss than details near the start or end.

What fills the window

  • Instructions that load on every turn, such as AGENTS.md
  • The running conversation, including the model's own replies
  • Tool results, which are often the largest share
