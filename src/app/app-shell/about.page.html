About JooKoi

It is a curated list of sites, not a crawl and not a search engine. Each source has a few facts you can filter on, such as what kind of site it is, whether it has an RSS feed or its own site search, and when the link was last checked.

Search sends you to the original site. Type a query, pick the sources, and the site's own search opens with your query filled in. Nothing is copied or summarised here, because the point is to get you to the real pages.

It is not a business. There is no advertising, no tracking and no plan to make money. It is for personal use and for friends and the local community, and it also serves as a place to try out a modern Angular application.

The list is small and edited by hand, so expect gaps. Browse the sources, read the source data on GitHub ↗, or go back to the front page.
